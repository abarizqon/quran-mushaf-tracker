💡 Panduan Integrasi Cepat untuk Developer

Modul ini dapat langsung dipakai di aplikasi Vanilla JS, React, Vue, Svelte, atau Next.js tanpa build step.

1. Instalasi / Import ES Module

<!-- Wadah tampilan Mushaf -->
<div id="myQuranApp" style="width:100%; height:100vh;"></div>

<script type="module">
  import { MushafEngine, MushafViewer } from './modules/quran-mushaf/index.js';

  // 1. Inisialisasi engine offline (CacheStorage API)
  const engine = new MushafEngine({ cacheName: 'app-mushaf-cache-v1' });

  // 2. Inisialisasi viewer UI dengan bilah progres 5-tier & tap fullscreen
  const viewer = new MushafViewer('#myQuranApp', {
    engine: engine,
    initialPage: 1,
    enableTapFullscreen: true,
    onPageChange: (page, details) => console.log('Halaman:', page, details),
    onJuzCompleted: (juz) => console.log('🏆 Juz Selesai:', juz)
  });
</script>

2. Fitur Baru Unggulan:

  • Bilah Progres Juz 5-Tier Dinamis: Emerald (1-25%) → Teal (26-50%) → Indigo (51-75%) → Amber (76-99%) → Solid Royal Gold (100% 🏆).
  • Mode Layar Penuh Murni via Tap: Cukup ketuk sekali di lembaran mushaf untuk menyembunyikan header/footer tanpa tombol melayang. Mushaf & card judul tetap berada tepat di tengah layar (*center*).
  • Modal Indeks Surat & Juz Terintegrasi: Ketuk card judul juz di atas untuk memilih surat dan juz secara langsung.
  • 100% Offline via CacheStorage API: Tidak membutuhkan koneksi internet setelah lembaran tersimpan di cache.
